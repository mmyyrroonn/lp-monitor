# 股票共池与代币精度

用户已指定：股票共池两边各计入；从股票池发现未知代币时查询精度。

每笔原始成交与池窗口只计一次。股票聚合分别按各股票原始数量和已有的前序 USDG 报价估值；没有报价仍保留该股票的成交计数与原始数量。提醒按池保持唯一，标签列出双方股票。

精度按 chain 4663 / 合约地址 / 查询区块及 hash 持久化。已知股票与 USDG 在启动时预取；采集发现新池后查询未缓存代币。缓存只用于查询区块及之后，不能把最新精度伪装为历史证据。重启复核已缓存区块 hash；失败保持 unknown，按退避重试，RPC 预算和关停错误向上传播。离线指标读取数据库缓存，不发 RPC。

不假设所有股票共用精度，不把精度成功当作报价可用。保留已有名单改动，不启动长期实测。
