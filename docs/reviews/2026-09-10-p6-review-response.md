# P6 独立复审处理记录

原始[独立复审](2026-09-10-p6-independent-review.md)保持不变。本记录针对其具体发现核对代码、复现缺陷并记录处理，不把修复意见全部视为既定需求。2026-09-10 最后一次冻结前，74 文件 / 740 测试通过，typecheck、lint、build 均退出 0；独立增量复查未发现剩余 Important/Blocking。最终构建的两小时运行结果仍须单独验收。

| 条目 | 处理与依据 |
|---|---|
| I-1 历史 anchor 限流 | 保留数字块查询的保守 1 RPS 历史预算。2 秒为轮询等待配置，完整周期包含 RPC 和处理时间；不自动提高预算或承诺每 2 秒获取完整结果。实际请求与分钟 anchor 用量单独计量。 |
| I-2 / I-3 截止时仍有积压 | 保留 incomplete / 非零退出，不把未完成覆盖改成通过。无其他错误但时限内未追完时记录 `duration-ended-with-backlog`；30 秒为有界收尾准入期限，超出后保留失败，不保证任意批次都能收尾。失败运行不再仅因经过原截止时间而标 `stopReason: duration`。 |
| I-4 停机丢失 follow 统计 | `follow` 在 finally 发布部分统计，异常路径标 complete=false；recorder 合并一次。回归覆盖先前已接受批次、曾经失败的尝试与随后 SIGINT，保留计数和失败历史。 |
| I-5 停机后的后续 RPC | 在每次 anchor/log 查询及身份核验的 request 准入前检查停机。身份核验内部可能包装异常，边界重新恢复用户停机语义。回归断言分钟解析中和启动身份核验中收到 SIGINT 后，不再出现后续实际请求；已有 raw 仍保留。 |
| I-6 / I-8 状态过期与 starting | status 严格绑定数据库和 scope，保留原始采样时间、年龄、观测状态及 freshness。默认 60 秒新鲜度阈值可通过库接口调整；过期或时间无效的活动状态显示 stale。starting 可读取；已结束状态作为历史事实保留，同时显示年龄。 |
| I-7 追赶采样偏差 | 每批开始和完成后采样，回归覆盖外层轮询尚未结束时的非零观测链头差距。链头仍是最后一次 RPC 观测，未知差距保持 null；不能用周期末 gap=0 证明独立实时链头无落后。 |
| I-9 本地错误归类 | 未知本地异常记录脱敏 `local-error`，RPC 类型错误保留原类别；不输出原始异常文本、URL 或凭据。回归注入含敏感样式 URL 的本地处理异常并验证产物不含原文。 |
| I-10 证据目录忽略规则 | 大体积 raw、逐范围文件、请求日志和数据库保留在本机，未提交 Git 并不等于删除。阶段报告绑定本机 manifest 和数据库快照；仅克隆仓库不能复核全部原始实录，交接时须另行复制这些目录与快照。 |
| I-11 冒烟构建归属 | 历史冒烟的代码清单在运行中取得，不能证明全部已加载模块。最终构建单独做启动前指纹及完整两小时验收，不声称历史冒烟就是最终构建。第二次长观察期间独立复审曾重新构建，结束前核对全部 98 个清单文件字节与其启动前指纹一致；记录这一事实，不声称期间从未 build。 |
| I-12 磁盘口径 | 阶段报告统计 SQLite+WAL，最终成本另列运行证据目录和各失败尝试体积。新增有符号净增长及明确命名的正增量，避免 WAL 收缩被累计为净增长。每批内联 registry 的去重存储属于后续优化，当前原始证据完整保留。 |

另修复了复审 M-5 相关的实测长时问题：原 FIFO 缓存在超过 2,048 批次时会顺序扫描全失效；现在按实际分钟区块范围选取批次、完整验证所选批次，容量满时不驱逐当前有效条目，并清理本 scope 已离开查询窗口的缓存。payload、分片与当前接受范围仍每次核验，默认全量验收路径不变。22 项覆盖测试包含 2,051 批次、窗口迁移、回访重验及分片变更。

其余建议不扩大成 P5 历史采集、自动交易、永久服务或新的存储体系。真实 reorg、阈值有效性及 LP 净收益不由这些工程测试证明。
